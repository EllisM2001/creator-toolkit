# Shared templates

`custom.json` is a JSON array of Post maker templates. Everyone who opens the toolkit gets
the templates listed here, ahead of the built-in ones.

To add one: open the Post maker, press **Design a template**, lay it out, then
**Save + download file**. Paste the contents of the downloaded `template-<id>.json` as an
entry in this array (or send the file to whoever maintains the repo). Overlay PNGs are
embedded in the file, so keep them reasonably small.
